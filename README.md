# Amazon Pricing & Discount Analysis (SQL)

## Overview

This project analyzes an Amazon product dataset using MySQL to understand how pricing discounts impact customer ratings and review volume.

## Dataset

- Amazon Product Dataset (Kaggle)
- Approximately 1,400+ products

## Tools

- MySQL
- DBeaver
- SQL
- GitHub

## Skills Demonstrated

- Data Cleaning
- SQL Queries
- Aggregate Functions
- GROUP BY
- CASE Statements
- Data Transformation
- Business Analysis

## Business Questions

- Which product categories have the highest average ratings?
- Which categories receive the largest discounts?
- Do larger discounts increase customer engagement?
- How do discounts affect customer ratings?

## Key Findings

- Higher discounts generally resulted in higher review volume.
- Lower discount products maintained slightly higher average ratings.
- Customer engagement increased with discount size, but satisfaction did not always increase.
